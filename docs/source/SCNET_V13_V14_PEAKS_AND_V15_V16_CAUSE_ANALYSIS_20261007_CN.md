## 2. V15的底座、学习原理与负结果

底座CLIP ViT-B/16，原生批准Stage1严格加载，文字/prompt在Stage2冻结。Stage1只学习prompt/缓存视觉特征，不是视觉主干额外训练120轮。新增：

- 早期共享/光谱rank32 patch适配，图像预测光谱路由。
- 四query两层局部decoder，输出独立局部512，直接进入推理。
- 单图全局768/局部512各自归一化，以固定0.7/0.3能量拼接L2。
- 每身份真实同camera/frame三谱加一张异camera图，P16K4/64图。
- 同学生提供的detached视觉特征进入可学习融合教师；EMA仅用于融合头，没有独立EMA主干或外部更强教师。教师分类、可信跨camera关系KL、可拒绝局部对应监督，I2T权重后期渐退。

正式40轮9.3493%/22.2951%，比V10/A40低2.5160/6.4481个百分点，首位净少413query。10轮10.2517%/25.0898%较好，20轮降到9.0947%/21.6081%，末轮小幅恢复，没有实现检索提升。

### 已证实的现象

40轮global/local训练ID准确率约99.59%/99.64%，教师训练ID100%；训练跨camera最难正负margin均值0.5972，排序loss0.00945。教师关系有效anchor均值63.9978/64且梯度非零。训练分类及训练排序充分拟合，但官方未见身份检索明显受损；符合训练身份过拟合/泛化脱节表现，不是新增loss完全未执行。

### 优先原因假设与设计不足

1. **教师缺少独立判别依据。** 它融合的是正在更新的同学生特征。训练分类正确被用作可信标准，不保证教师识别未见身份或它提供的局部关系比学生更好。早期16张训练图拟合探针只证明通路可执行，不能支持教师泛化优势。
2. **新局部分支未经独立检索质量验证就固定进入最终输出。** 四个query没有人体部位真值、可见性真值或预训练部位对应认证，可能学训练场景相关线索；是否背景依赖/部位错配尚未有特征或反事实证据。固定30%局部能量可能让弱局部信息影响排序，需要拆分branch诊断确认。
3. **多个变量一起变化使归因不足。** 主干适配/局部结构/教师、采样、I2T日程、分组LR及描述子几何都更改。小流程通过不证明这些因素组合可泛化。不能把结果只归因I2T降权、局部结构或某个LR。
4. **特征与记忆目标同时变化。** EMA只有教师头，bank来自此前特征，学生局部projection仍更新。目标漂移有实现依据，但它是否是检索受损主因需独立诊断。

## 3. V16的底座、研究机制与失效

底座公开DINOv2 ViT-B/14 with4 registers，self-supervised LVD142M视觉预训练，未使用CLIP Stage1。它提供CLS和patch特征，register用于处理一类低信息区域高范数token伪影，不是人体前景/部位识别器。[官方模型卡](https://github.com/facebookresearch/dinov2/blob/main/MODEL_CARD.md)。

方法：等比例280×140/补边mask；按实际有效源尺寸16像素尺度合并原生支持单元；CLS768+支持单元512；同frame三谱局部循环、身份竞争margin拒绝/唯一端点/弱谱容量限制；按身份/camera存证据集合，监督可靠异camera对应。只有视觉ID/余弦排序，无I2T/可学习融合教师。原生源尺寸是启发式支持量，不是熵或可见性真值。

截至09:24仅生成10/20轮评价：5.0059%/19.6877%、5.8723%/22.0921%；30轮训练已完成，评价未生成，正式40轮结果未知。

### 已证实的失效

- 19—30轮连续12个完整轮次，cross_camera_consensus_anchors/evidence loss均0；30轮近期3个探针该分支梯度0。6—18轮加权证据loss仅约3e-9—1.9e-7，已极弱。原生支持聚合仍执行，但三谱证据桥未形成持续生产监督。
- 30轮训练global/patch ID约99.34%/99.22%，最难正负余弦margin均值约-0.00017075，metric1.31451253。该loss形式为softplus((s_neg-s_pos+0.1)/0.1)，当最难正负相似度相等时参考值softplus(1)=1.31326169，实际仅高0.00125084。
- 因此训练分类拟合不等于训练角度排序有效；最难跨camera正负间隔几乎没有建立。这不证明所有特征相同，不能仅凭该数值宣布全面特征塌缩。

### 代码支持的优先排查

1. **硬筛选门槛在正式竞争规模下拒绝过多。** 必须同时三谱循环、最弱边>0.15、相对错误身份margin>0.02；错误身份越多，取最大相似度的门槛越难通过。真实smoke P2仅1个其他身份，生产P16为15个，数据读取契约通过不能替代P16机制可用覆盖验证。
2. **门槛比较的相似度对象不同。** 正分数用三谱两两最弱边，负分数用融合三谱向量对其他身份单元的最大相似度；两者不保证同分布/标尺。该定义可能苛刻地拒绝有用关系，需要分解循环率、阈值率、margin率。当前日志tri_spectral_cycle_candidates实际计的是所有筛选之后legal.sum，不是真正未经margin筛选的原始循环数，不能由该字段0判断循环本身断了。
3. **分类与检索几何可分离。** 源码训练ID使用BN后特征，排名/推理使用BN前特征归一化。若raw特征包含强公共分量和很小身份差异，BN可放大小差异帮助分类，而原归一化角度仍不易区分；这是数学上可发生的机制，需实物特征范数、方差/谱和正负分布验证。
4. **原生几何平均与域适配可能不足。** 空中TIR只有少数粗单元，平均可能混合头肩/身体/背景，输入mask只屏蔽补边不屏蔽原crop内背景。一般DINO语义先验不自动等于RGB/NIR/伪彩TIR身份一致性，是否这些因素拖累要有匹配baseline。

通用视觉模型的细粒度身份区分局限也被相关研究指出，但外部论文不能证明本实验具体原因。[相关一手研究](https://openaccess.thecvf.com/content/ICCV2025/papers/Huang_Generalizable_Object_Re-Identification_via_Visual_In-Context_Prompting_ICCV_2025_paper.pdf)。

## 4. 对此前验证的修正

此前CPU/CUDA/恢复/真实4轮smoke主要验证数值、路径、文件与预算。V15额外训练图教师fit也只覆盖少量训练身份；V16生产P16竞争条件和长程筛选覆盖没有被短P2验证充分代表。这个验证缺口应明确承认，不能用工程PASS替代新框架有效性。

V15存在明确整体负结果，V16存在持续监督失活和训练排名不足；在分离这些问题前，不支持再堆模块、直接放宽阈值或重复新版本长训练。可优先在训练侧做匹配P16机制诊断、全局/局部分支质量、教师相对学生的异camera关系、角度几何与hard-filter分解。新颖性仍按用户CVPR原则由具体差异、有效机制和控制结果证明；失败不通过改正式checkpoint或评价协议补救。
